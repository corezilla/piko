# 智能流程推动器设计验证

Document ID: slinky-intelligent-process-design-checks
Version: 0.3.0-draft.1
Status: Draft
Date: 2026-09-16

承接 system-design draft.29、SRS draft.6、Interface Control draft.6。本文件是设计oracle，不是已执行的产品验证。旧固定Stage及复杂外部契约fixture不能充当本轮验收。

| ID | 场景 | 预期 |
|---|---|---|
| IP-01 | 相同阶段出现不同业务问题 | PM基于证据作不同安排，不由固定图/错误码强制同一动作 |
| IP-02 | PM提出越权、改用户约束或过期版本操作 | 代码拒绝或转用户批准；智能不能绕过约束 |
| IP-03 | 同一决定重复送达 | 不重复执行已记录动作；保留本地一致性，不宣称跨系统exactly-once |
| IP-04 | 三个IR参加Review，一个失败 | 三个独立Piko任务事实均保留；不将一个实例等同整队 |
| IP-05 | PM决定改派专家 | 新任务包含原失败、部分结果和已做操作；历史不覆盖 |
| IP-06 | PM认为需用户介入 | 待用户事务包含问题、影响、尝试及明确所需处理，无自动猜测决定 |
| IP-07 | 任务结果未知或取消仅受理 | 查询Piko确认，不伪报失败/停止，不盲重派副作用 |
| IP-08 | Piko返回记忆变更建议 | 正式Memory在验收前不变；Piko无直接写正式记忆权限 |
| IP-09 | 记忆建议基于旧版本、越权或包含Secret | 不覆盖现版本；保留冲突/拒绝原因，由授权角色处理 |
| IP-10 | 接受后索引失败 | 正式内容和索引状态区分，显式报告失败，可重建派生索引 |
| IP-11 | LLMTier暂不可用然后恢复 | 各自运维；Slinky协调影响，Piko处理执行，恢复不等于任务完成 |
| IP-12 | 只有诊断权限却请求重启/清库/probe | 不执行，提交授权处理；不临时扩权 |
| IP-13 | token usage缺失、估算、真实零 | 三者可区分，重复查询不重复累计，不计算Coding Plan费用 |
| IP-14 | 普通多Agent房间讨论和附件 | 标准身份/消息/回复/media；不要求旧自定义envelope/trigger/内容服务 |
| IP-15 | 编码者引用旧Slot/Seat/Invocation/Cost冻结包 | 被设计范围审查拒绝；必须使用当前简化边界 |
| IP-16 | 设计尚无生产实现 | 评审设计充分性，不要求实现先完成；运行验收仍独立标NOT_RUN |

Memory的索引模型、向量维度和检索测试在其内部设计细化。任务字段、标准模型surface及统一Usage字段由接口双方对齐。上述未实施项不等于本次业务方向尚待用户决定。

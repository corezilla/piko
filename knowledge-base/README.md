# Knowledge Base

This directory is the human-readable static knowledge site for Piko.

## Content boundary

- `docs/` contains published knowledge pages.
- `assets/` contains images, attachments, and site assets referenced by pages.
- `site/` contains the static-site configuration and templates.
- Product UI belongs to `webui` or `apps/<webui>` and is not implemented here.
- Project RAG publication remains governed by `rag/project-ingestion-manifest.jsonl`; this static site does not enable Q&A, vector indexing, or external retrieval.
- Runtime Activation is independent and remains disabled unless separately approved.

## Preview and build

No site generator or page content has been selected yet. Build, internal-link, asset, and duplicate-page checks are `N/A (empty skeleton)` until the first content cohort is added.

## Publication status

The directory is an initialized, Git-tracked skeleton only. It has not been deployed or externally published.
